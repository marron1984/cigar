# 🍂 葉巻大辞典 — Cigar Encyclopedia & Note

葉巻（シガー）の**基礎知識・国別・太さ別・価格別・喫煙具**を体系化した総合事典と、
吸った一本を書き留める**記録ノート**を備えた、静的Webアプリです。

## 特徴

- **オフライン完結** — HTML / CSS / バニラJavaScript のみ。ビルド不要、サーバー不要。
- **記録データはブラウザ内に保存** — `localStorage` に保存し、外部送信は一切なし。JSONでエクスポート／インポートも可能。

## コンテンツ構成

| セクション | 内容 |
|---|---|
| 📖 **基礎知識** | 葉巻とは／構造（ラッパー・バインダー・フィラー等）／吸い方5ステップ／テイスティング用語／ラッパーの色分類／歴史／マナー／用語集 |
| 🌎 **国・産地別** | キューバ、ドミニカ、ニカラグア、ホンジュラス、メキシコ、エクアドル、アメリカ、ブラジル、カメルーンの9か国 |
| 📏 **太さ・サイズ別** | リングゲージの解説／主要ビトラ10種の寸法・喫煙時間比較表／太さ別ガイド／形状分類 |
| 💰 **価格帯別** | ドライシガーからハイエンドまで5段階／価格を左右する要因 |
| 🧰 **喫煙具・保管** | カッター、ライター、ヒュミドール、灰皿、ケース、加湿具／保管の基礎知識 |
| 📝 **記録ノート** | 銘柄・産地・サイズ・価格・★評価・感想の記録／検索／統計／エクスポート |

## 使い方

`index.html` をブラウザで開くだけです。

```
.
├── index.html         # ページ本体
├── css/style.css      # スタイル（シガーラウンジ風テーマ）
├── js/
│   ├── app.js         # ナビゲーション & 事典レンダリング
│   └── note.js        # 記録ノート（localStorage）
└── data/data.js       # 事典データ
```

## 情報の収集について

各カテゴリ（国別・太さ別・価格別・喫煙具・基礎知識）ごとに情報を収集し、
専門サイト等で事実確認のうえ日本語で編集・収録しています。掲載の価格・仕様は目安であり、
銘柄や販売店により異なります。
